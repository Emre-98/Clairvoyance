# Clairvoyance

A lightweight game recorder for Windows. It records your League of Legends, Counter-Strike 2 and
Deadlock matches automatically and puts the moments that matter on a clickable timeline.

This repository holds only the official releases (installer and update files). The source code is
private.

## Download

1. Download `Clairvoyance_<version>_x64-setup.exe` from the
   [latest release](https://github.com/Emre-98/Clairvoyance-releases/releases/latest) and run it
   (no admin rights needed).
2. Optional: check the download. In PowerShell, `Get-FileHash .\Clairvoyance_<version>_x64-setup.exe`
   must show the SHA-256 listed in that release's notes.
3. Clairvoyance keeps itself up to date from this page and asks before installing an update.

Official builds check at start-up that they haven't been modified; downloads from anywhere else
aren't official.
